# Simple Shop Web Application

## Overview
This project is a Single Page Application (SPA) built with Angular to showcase products, categories, and provide a shopping experience for users. It interacts with a FAKE API to fetch product and category data.

## Features
- **Home Page**: Displays product categories and featured products.
- **Product Search**: Allows users to search for products by name.
- **Product Details Page**: Provides detailed information about a selected product.
- **Categories Page**: Lists all product categories.
- **Cart Page**: Enables users to view and manage cart items.
- **Checkout Page**: Implements a checkout process.

## Technical Stack
- **Framework**: Angular 14+
- **CSS Framework**: Tailwind CSS (or Bootstrap, Material as alternatives)
- **API**: Consumes a FAKE API for data fetching

## Installation & Setup
### Prerequisites
Ensure you have the following installed:
- Node.js (>=14.x)
- Angular CLI (>=14.x)

### Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/Guantaijp/shop-webapp>
   cd shop-webapp
   ```
2. Install dependencies:
   ```bash
    npm install
    ```
3. Start the development server:
4. ```bash
    ng serve
    ```
5. Open the browser and navigate to `http://localhost:4200/` to view the application.
6. You can now interact with the application.
7. To stop the server, press `Ctrl + C` in the terminal.
